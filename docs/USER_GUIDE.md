# 使用指南

主搜索目前使用英文词或词的一部分，回车或点击候选项进入对应中心页。目录筛选也可按中文释义找词。左目录可在“主题 / 词族”切换、收起并独立滚动。

单击节点查看详情，双击设为新中心。节点聚焦后 Enter 查看，Shift-Enter 设为中心。`+ / −` 展开或收起分支；“阅读视图”优先保持文字可读，“看全图”展示整体。词史独立占位，长内容内部滚动，可以折叠。

“高频优先”筛出 NGSL 对照命中的目标词，“其余词”保留剩余词。主动搜索筛选之外的词时会显示一条临时定位记录，点“恢复筛选”退出临时定位。

收藏、已掌握是自己的学习标记，当前没有间隔重复或自动复习安排。网页记录保存在当前浏览器，清理站点数据或更换浏览器不会自动迁移记录。Mac 版有自己的本地记录。迁移时先“导出进度”，再在另一端“导入进度”。导入会用文件里的收藏／掌握集合替换当前集合，建议先导出备份。

Mac 快捷键：Command-F 搜索、Command-R 重新载入、Command-Q 退出。关闭窗口后可从 Dock 再打开，支持原生全屏和缩放。核心词库离线可用，外部来源网页需要联网，朗读取决于系统是否有英语语音。
